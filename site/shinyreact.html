Plotomics Live shows where Shiny React can really extend what is practical in a bioinformatics Shiny application. The app keeps Shiny and R for reactive computation, while using React, TypeScript, and WebGL for the frontend. This makes it possible to build highly interactive visualizations for large and complex biological datasets, including a UMAP with more than 580,000 cells, 1 million spatial transcript detections, interactive genome views, molecular structures, networks, and other genomics visualizations.

In a traditional Shiny workflow, many of these views would require server-rendered plots, aggressive downsampling, or substantial custom JavaScript and widget infrastructure. With Shiny React, these frontend technologies can be used directly while still communicating naturally with the Shiny backend. For computational biology, where datasets are increasingly large, high-dimensional, and inherently interactive, this combination lets Shiny remain the analysis engine while React and WebGL handle the visualization experience.

What Shiny React enabled in Plotomics Live

  • R stays the analysis engine. Existing Shiny reactivity and scientific R workflows remain on the server.
  • React becomes the visualization layer. Direct use of React, TypeScript, WebGL, Canvas, and the JavaScript visualization ecosystem.
  • 584K-cell UMAP, fully interactive. ~7 MB binary typed arrays → browser → GPU, rather than server-rendering every view.
  • 1M spatial transcript detections. Compact binary coordinates and GPU rendering make million-point spatial exploration practical.
  • Beyond traditional plots. Interactive gene networks, 3D AlphaFold structures, genome browsers, spatial views, Hi-C, ATAC, and high-dimensional arrays.
  • Native Shiny reactivity from React. React state can become Shiny inputs, and R results return directly as reactive outputs.
  • No visualization re-mount on every update. Components update data/options directly, avoiding unnecessary GPU reallocation.
  • One scientific computation, multiple renderers. R computes the result once; React/WebGL and ggplot2 can visualize the same underlying result.

The blocker in traditional Shiny: these experiences are possible, but often require custom JavaScript bindings, htmlwidgets, manual message passing, serialization, and lifecycle management.

Shiny React removes that integration barrier.
